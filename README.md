# 🌱 HydroFlow – Smart Hydroponics System

HydroFlow is a smart hydroponics monitoring and management website designed to help users monitor plant health and hydroponic system conditions.

## 🚀 Features

- 🌱 Smart hydroponics dashboard
- 📊 Sensor data monitoring
- 💧 Hydroponic system information
- 🔍 Plant search
- 📷 Plant/camera search
- 🩺 Plant health information
- 🌿 Interactive and responsive interface
- 📱 User-friendly design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js
